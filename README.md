# My Portfolio

This is my personal portfolio website showcasing my projects, skills, and experience as a frontend developer.

## What was your favorite part of building this?

My favorite part of building this portfolio was designing and implementing the user interface that reflects my personality and skills.

## What was the hardest, and how did you handle it?

The hardest part was managing large files and ensuring the project was optimized for deployment. I encountered issues with GitHub's file size limits due to the inclusion of unnecessary files like `node_modules`. To handle this, I carefully updated my `.gitignore` file to exclude such files and used tools like `git-filter-repo` to clean up the Git history. This helped me streamline the repository and resolve the issues effectively. Also after everything being correct , the image couldn't load on the frontend page.
